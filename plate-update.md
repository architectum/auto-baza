# 📋 План реалізації оновлення номерних знаків (plate-update.md)

Цей план описує покроковий процес розширення функціоналу номерних знаків у веб-додатка **АвтоБаза**: від розпізнавання штучним інтелектом (Google Gemini) до кастомізації у формі та сучасного візуального рендерингу в компоненті `LicensePlate`.

---

## 1. Оновлення типів даних (`src/types/car.ts`)
- [x] 1.1. Додати нові опціональні поля у інтерфейс `Car`:
  - `country?: string` — код країни (`UA`, `PL`, `D`, `LT`, `CZ`, `RO`, `MD`, `GB`, `US`, `OTHER`).
  - `plateColor?: string` — колір номера (`white`, `yellow`, `red`, `green`, `black_military`, `black_old`, `blue`).
  - `plateForm?: string` — форма номера (`standard`, `square_us`, `square_moto`).

## 2. Створення констант для вибору номерів (`src/features/cars/constants.ts`)
- [x] 2.1. Створити константи з переліками опцій (із зрозумілими назвами українською):
  - `COUNTRY_OPTIONS`: список країн (з прапорцями/кодами, за замовчуванням `UA`).
  - `PLATE_COLOR_OPTIONS`: список кольорів номерного знака (білий, жовтий, червоний, зелений EV, чорний військовий, чорний старий, синій поліція).
  - `PLATE_FORM_OPTIONS`: список форм (широкий прямокутний, квадратний США/Японія, квадратний мото).

## 3. Інтеграція зі штучним інтелектом (`src/services/ai.ts`)
- [x] 3.1. Оновити промпт та JSON Schema функції `extractFromPhoto`:
  - Додати визначення полів `country`, `plateColor` та `plateForm`.
  - Передати Gemini точні списки можливих значень для кожного поля.
- [x] 3.2. Перевірити та обробити отримані від AI дані в `AIFillSection.tsx` / `CarForm.tsx`.

## 4. Оновлення форми створення/редагування авто (`CarForm.tsx` & `CarProfile.tsx`)
- [x] 4.1. Додати нові поля у списки `CAR_FIELDS` в `CarForm.tsx`.
- [x] 4.2. Додати блок вибору параметрів номерного знака у `CarForm.tsx`:
  - Країна (селект/вибір із списку з `UA` за замовчуванням).
  - Колір номера (селект/чіпи з кольоровими маркерами).
  - Форма номера (широкий, квадратний США, квадратний мото).
  - Інтерактивне прев'ю номера прямо у формі.
- [x] 4.3. Оновити обробку збереження авто в `CarProfile.tsx` для запису `country`, `plateColor` та `plateForm` у Firestore.

## 5. Рефакторинг та стиль компонента номерного знака (`src/features/cars/LicensePlate.tsx`)
- [x] 5.1. Розширити props компонента `LicensePlate`: `country`, `plateColor`, `plateForm` із значеннями за замовчуванням (`UA`, `white`, `standard`).
- [x] 5.2. Реалізувати сучасний дизайн українського номера:
  - Ліва темно-синя смуга (`#002B7F`) без тризуба/герба.
  - Літери `UA` білим кольором на синьому тлі.
- [x] 5.3. Реалізувати стилі для інших країн (синя плашка з єврозірочками або кодом країни для ЄС/США).
- [x] 5.4. Реалізувати кольорові схеми:
  - `white`: Білий фоновий номер з чорними літерами (стандартний цивільний).
  - `yellow`: Жовтий фон з чорними літерами (таксі / пасажирський транспорт).
  - `red`: Червоний фон з білими літерами (транзитний / тимчасовий).
  - `green`: Білий фон із зеленими літерами та зеленими елементами (для електромобілів EV).
  - `black_military` / `black_old`: Чорний фон з білими літерами (військові / спецтехніка / старий формат).
  - `blue`: Синій фон з білими літерами (поліція / спецслужби).
- [x] 5.5. Реалізувати геометричні форми (`plateForm`):
  - `standard`: Однорядковий прямокутний номер.
  - `square_us`: Дворядковий квадратний номер (США/Японія 300x150 мм).
  - `square_moto`: Дворядковий компактний номер (Мото 220x174 мм).
- [x] 5.6. Забезпечити 100% зворотну сумісність: якщо передано лише рядок `plate` (старі записи), відображати як стандартний український білий прямокутний номер.
