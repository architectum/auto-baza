# АвтоБаза

**АвтоБаза** — це сучасний, мобільний веб-додаток (PWA) для автомайстрів та СТО, що допомагає зручно вести облік автомобілів клієнтів та історію їх обслуговування. Завдяки вбудованим інструментам штучного інтелекту (Google Gemini), рутинні задачі, такі як введення даних авто чи запис історії ремонту, стають максимально швидкими та зручними.

---

## ✨ Основні можливості

- **Автентифікація через Google:** Швидкий та безпечний вхід за допомогою акаунта Google (Firebase Auth).
- **База автомобілів клієнтів:** Збереження детальної інформації про авто (марка, модель, номер, рік випуску, колір, тип кузова, пробіг) та контактів клієнта.
- **Історія обслуговування:** Детальний лог робіт для кожного авто (проблеми, рішення, нотатки, записи пробігу) з відстеженням дати та часу.
- **AI-асистент (Голосовий ввід):** Можливість продиктувати дані про авто або історію ремонту голосом. Gemini AI автоматично розпізнає ключову інформацію і рознесе її по правильних полях.
- **AI-асистент (Фото-сканер):** Додавайте нове авто просто зробивши фото його передньої частини. ШІ розпізнає номерний знак, марку та модель автомобіля.
- **PWA (Progressive Web App):** Можливість "встановити" додаток на головний екран смартфону (iOS/Android) та зручно користуватися ним як нативним застосунком.
- **Гнучка кастомізація:** Підтримка світлої/темної/системної тем оформлення, а також можливість вибору акцентного кольору інтерфейсу (Premium дизайн).

---

## 🛠 Технологічний стек

- **Frontend:** React 19, TypeScript, Vite
- **Стилізація:** Tailwind CSS v4, Lucide React (іконки)
- **Backend / Database:** Firebase (Cloud Firestore)
- **Authentication:** Firebase Auth (Google Provider)
- **Штучний інтелект:** Google GenAI SDK (моделі Gemini)
- **Хостинг:** Firebase Hosting

## 🚀 Інструкція зі встановлення (Для розробників)

### 1. Клонування репозиторію
```bash
git clone git@github.com:architectum/myautocto.git
cd myautocto
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Налаштування Firebase та зовнішніх API
1. Створіть новий проєкт у [Firebase Console](https://console.firebase.google.com/).
2. Увімкніть **Authentication** і додайте провайдер **Google**.
3. Створіть базу даних **Firestore Database** і встановіть правила з файлу `firestore.rules`.
4. Отримайте конфігурацію Firebase додатку.
5. Отримайте API ключ для **Google Gemini** у [Google AI Studio](https://aistudio.google.com/).
6. Скопіюйте файл `.env.example` у файл `.env` та заповніть його своїми даними:

```env
VITE_FIREBASE_API_KEY=ваш_ключ
VITE_FIREBASE_AUTH_DOMAIN=ваш_домен.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=ваш_id_проєкту
VITE_FIREBASE_STORAGE_BUCKET=ваш_bucket.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=ваш_sender_id
VITE_FIREBASE_APP_ID=ваш_app_id
GEMINI_API_KEY=ваш_ключ_gemini
```

### 4. Запуск розробницького сервера
```bash
npm run dev
```
Після цього додаток буде доступний за адресою `http://localhost:3000`.

## 📖 Інструкція по використанню додатку

### 1. Вхід у додаток
Відкрийте додаток і натисніть кнопку **«Увійти через Google»**. Виберіть свій Google-акаунт. Всі ваші дані (авто та їх історія) будуть прив'язані виключно до вашого акаунта.

### 2. Головний екран (Список авто)
На головному екрані ви бачите список всіх доданих автомобілів. 
- Для **пошуку** скористайтеся рядком зверху — можна шукати за номерним знаком, ім'ям клієнта чи номером телефону.
- Щоб **додати нове авто**, натисніть круглу кнопку **«+»** у правому нижньому куті екрана.

### 3. Додавання нового авто
При додаванні авто ви перейдете на форму створення профілю:
- **Заповнення вручну:** Ви можете вручну ввести номер, марку, модель, вказати рік, обрати колір, тип кузова та записати контакти клієнта.
- **Магія ШІ (Фото):** Натисніть іконку 📷 (камера) у блоці «Автозаповнення AI», зробіть фото авто або завантажте його з галереї. Додаток сам розпізнає номер, марку і модель.
- **Магія ШІ (Голос):** Натисніть іконку 🎤 (мікрофон), продиктуйте: *"Тойота Камрі чорного кольору, седан, 2018 року, номер АХ 1234 ВВ, клієнт Олексій, телефон 050 123 45 67"*. Асистент сам заповнить усі поля!
- Натисніть **«Зберегти дані авто»**, щоб створити запис.

### 4. Історія обслуговування
Натисніть на будь-яке авто зі списку, щоб відкрити його картку. Внизу знаходиться блок **«Історія»**:
- **Оновлення пробігу:** Натисніть кнопку **«Пробіг»** над записами, щоб швидко ввести новий кілометраж. Додаток автоматично вирахує різницю з попереднім значенням.
- **Додавання робіт голосом:** Унизу екрана є панель **«Надиктувати запис»**. Натисніть на мікрофон і скажіть, наприклад: *"Поміняли масло і фільтри, пробіг 145 тисяч"*. Gemini автоматично розпізнає це як "Рішення", виокремить пробіг та створить запис.
- Записи автоматично сортуються від найновіших до найстаріших і мають кольорове кодування (Проблема, Рішення, Нотатка, Пробіг).

### 5. Налаштування додатку
Натисніть на іконку **шестірні (⚙️)** у правому верхньому куті головного екрана:
- Змінюйте тему (Світла / Темна / Як у системі).
- Обирайте колірний акцент додатку під свій смак (Синій, Зелений, Червоний, Фіолетовий тощо).
- З налаштувань також можна вийти з акаунта.

### 6. Встановлення як додаток (PWA)
Якщо ви відкрили застосунок у браузері на телефоні (Chrome або Safari):
- **Android (Chrome):** Натисніть на меню браузера (⋮) і виберіть *"Додати на головний екран"* або *"Встановити додаток"*.
- **iOS (Safari):** Натисніть кнопку "Поділитися" (квадрат зі стрілочкою) і виберіть *"На початковий екран"*.
Тепер АвтоБаза буде виглядати і працювати як звичайний мобільний додаток, без адресного рядка браузера!

У нас з'явилось поле скільки часу було потрачено на рішення і також є поле вартості рішення: тобто скільки ми заробили імплементуючи це рішення, отже ми можемо додати кілька цікавих графіків, де будемо показувати як змінюється вартість рішень в залежності від того скільки часу було витрачено на рішення і як змінюється вартість нашого часу, тобто рейт скільки гривень за годину, по дням тижня, рахуючи середній рейт по рішенням за день, але при цьому відображати на цьому ж графіку додатковий стовпчик який показує кількість рішень. Також потрібно додати можливість вибирати період для якого ми хочемо побачити статистику, щоб можна було дивитись статистику за місяць, і листати вліво вправо по місяцям, перебудовуючи поточні графіки на нові періоди, там же де зараз ми бачимо статистику за тиждень і можемо листати вліво і вправо, щом можна було перемкнути на режим місяць і в цьому режимі потрібно показати на графіку стовпчики на 30 днів, кожен день окремим стовпчиком, кількості звернень клієнтів у день, як це зараз зроблено на графіку потижневої статистики. При цьому функціонал потижневої статистики має залишитись режимом перегляду за замовчуванням.
